# Telco Customer Churn Analysis using Power BI Dashboard

## Overview
Customer churn and retention analysis for a telecommunications business built as part of the Future Interns Data Science & Analytics Track.

## Key Findings:
- Churn Rate: 26.54% across 7,043 customers
- Month-to-month contracts have the highest churn
- Fiber optic customers churn at 41.89%
- Electronic check users churn at 45.29%

## Tools Used:
- Microsoft Power BI Desktop

## Dataset:
Telco Customer Churn Dataset (IBM Sample) — Kaggle
